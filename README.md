# BlogSpace · Frontend (early version)

An early version of the React frontend for BlogSpace, a full-stack blogging platform. It includes pages for browsing, reading, writing and editing posts, comments, login (including Google), a profile and a dashboard.

The source files are stored in a single folder rather than the usual `src/` layout. The organised, runnable version is [blogspace-1](https://github.com/aksharaagarwal21/blogspace-1), and the backend is [blogspace-2](https://github.com/aksharaagarwal21/blogspace-2).

## Tech stack

React · React Router · Axios
